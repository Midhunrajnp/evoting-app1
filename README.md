# E-Voting System

## Overview

A simple E-Voting System developed using Java and Spring Boot to simulate online voting operations and result management.

## Features

* User voting system
* Candidate management
* Vote result display
* Backend API handling
* Basic project structure using Spring Boot

## Tech Stack

* Java
* Spring Boot
* Maven
* GitHub

## Tools Used

* Maven
* GitHub

## Project Goal

To understand backend application development using Java Spring Boot and build a simple voting management system.
